Integration Code

Add this to your website to embed the widget:

<script src="https://cdn.askdocs.ai/widget/v1/askdocs-widget.js"></script> <script> const widget = new AskDocsWidget({ apiKey: 'your_api_key_here', apiUrl: 'https://api.askdocs.ai', botName: 'Support Bot', primaryColor: '#3b82f6', position: 'bottom-right', welcomeMessage: 'Hi! How can I help you today?', placeholder: 'Ask a question...', showBranding: true, debug: false }); // Optional: Listen to events widget.addEventListener('message:received', (data) => { console.log('Bot response:', data.message); }); </script>

Advanced Usage

// Programmatic control widget.open(); widget.close(); widget.sendMessage('Hello!'); // Get widget state const messages = widget.getMessages(); const state = widget.getState(); // Update configuration widget.updateConfig({ primaryColor: '#ff6b6b', botName: 'New Bot Name' }); // Event listeners widget.addEventListener('widget:ready', () => { console.log('Widget is ready!'); }); widget.addEventListener('error', (data) => { console.error('Widget error:', data.error); }); // Cleanup widget.destroy();
